Pelagic Dynamics remains the primary brand on the main page. Compound Future is presented as the studio's first released product.

## Upload to GitHub

1. Open the `pelagicdynamics.github.io` repository.
2. Replace `index.html`.
3. Replace/update the `assets` folder.
4. Replace `compound-future/index.html`.
5. Keep your existing `compound-future/privacy/index.html` file unless you intentionally want to replace it.
6. Commit the changes to the branch used by GitHub Pages (normally `main`).
